# 2026.11.02.1 (2026-11-02)

## Changes

- Make section titles, paths, and labels explicit so slash-containing headings cannot shadow nested paths.
  `:section:` now always selects a literal title; use `:section-path:` with one heading component per line, or `:section-label:` with an RST label.
- Give exclusions the same explicit modes: literal titles in `:exclude-sections:`, labels in `:exclude-section-labels:`, and JSON arrays of heading components in `:exclude-section-paths:`.
- Replace the Python API's overloaded `selector` argument with exactly one of `title`, `path`, or `label`.
  Migrate slash-delimited paths and hash-prefixed labels to their explicit modes before upgrading.
