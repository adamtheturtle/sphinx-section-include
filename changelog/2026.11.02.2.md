# 2026.11.02.2 (2026-11-02)

## Changes

- Add opt-in `:heading-style: rubric` to present all included headings as native Docutils rubrics, preserving inline formatting, anchors, references, and source locations without adding document sections.
  `:include-heading:` continues to control the selected heading, and ordinary section headings remain the default.
- Support the same heading style in the Python `copy_section()` API.
- Annotate `setup()` with Sphinx's `ExtensionMetadata` TypedDict.
